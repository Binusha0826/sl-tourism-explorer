# Sri Lanka Tourism & Weather Explorer

Interactive dashboard that compares 7-day weather across Sri Lankan tourist destinations
and ranks them with a simple "travel score".

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Tech
Python, Streamlit, Pandas, Plotly, Open-Meteo API
